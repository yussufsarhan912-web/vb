# Veylon — GitHub / Vercel version

This is the original Veylon marketing website with the client portal removed. Pages are already built: no install, build command, environment variables or database setup are required for deployment.

Upload the extracted contents to the root of your GitHub repository and import that repository in Vercel. The included vercel.json selects the public folder and the correct routing automatically. Upload the extracted files, not the ZIP itself.

The original design, media, animations, portfolio, pricing, services, clipping, process, about and application form are retained. Portal navigation, the homepage portal showcase and portal-specific FAQ/copy are removed. The form sends applications to the existing Veylon inbox on the original hosted site; keep that site active. Team access opens that existing inbox/website CMS in a new tab. No passwords or private portal data are included here.

The complete original portal code is preserved separately in Veylon-Client-Portal-Backup.zip. The original hosted portal was not modified or deleted.

The source folder is retained for future edits. It is not involved in deployment. To rebuild after editing source, run npm install then npm run build inside source; this regenerates the public pages. All supplied images and MP4s are local files. YouTube videos retain their original YouTube embeds.
